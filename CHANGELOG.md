## How to Update This File

**When making organizational changes**:
1. Add to `[Unreleased]` section under appropriate category
2. Categories: Added, Changed, Deprecated, Removed, Fixed
3. On milestone: Move `[Unreleased]` to new version section with date

**Example**:
```markdown
## [Unreleased]

### Added
- New project: ProjectName

### Changed
- Updated CODE_OF_CONDUCT.md with new guidelines
```

**Release process**:
```markdown
## [1.1.0] - 2025-11-01

### Added
- New project: ProjectName

### Changed
- Updated CODE_OF_CONDUCT.md with new guidelines
```
