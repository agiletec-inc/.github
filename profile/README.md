## 🚀 Getting Started with Our Tools

### Neural - Quick Start

```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5:3b

# Clone Neural
git clone https://github.com/agiletec-inc/neural.git
cd neural

# Build CLI
cd src-tauri
cargo build --bin neural-cli --release

# Translate!
./target/release/neural-cli translate README.md --to Japanese --output README-ja.md
```
